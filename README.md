# DS-2002 Project 2 — Retail Sales Lakehouse

This project builds on my midterm by turning my retail sales star schema into a streaming data lakehouse in Databricks. The goal was to pull together near-real-time fact data with reference dimension data from three different source systems — Aiven MySQL for the product and supplier dimensions, MongoDB Atlas for item types, and a Databricks Volume for the date dimension — and run it through a bronze, silver, gold medallion setup. I took the fact table from my midterm and split it into three JSON files for 4-month chunks of sales, then used Spark Structured Streaming to read them one at a time so each file acts like its own streaming interval. At the silver layer I joined the streaming bronze table to all four dimension tables to make it actually queryable, and the gold layer runs SQL queries on top to answer business questions like top suppliers by movement, best selling products, and sales by item type over time. I originally planned to use Azure SQL but UVA's Azure wouldn't let me create resource groups, so I switched to Aiven since the rubric says "a Cloud service database system like Azure SQL" and Aiven runs the same MySQL 8 backend. The final setup shows how static reference data and streaming fact data can be tied together to answer real questions, and how the medallion pattern turns a messy data flow into something useful.
